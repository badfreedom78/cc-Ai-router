Claude Code 接入

把下面的配置写入 Claude Code，即可让其请求经过智能路由。

方式一：环境变量

在启动 Claude Code 的终端里设置，仅对当前会话生效。

方式二：settings.json

写入 %USERPROFILE%\.claude\settings.json（用户级） 或项目内 .claude/settings.json，持久生效。

路由逻辑速览

请求先经 Router 模型打分（复杂度 / 推理 / 风险），再映射到 easy → balanced → strong 三档； 同档内按能力（视觉 / 音频）与优先级挑选具体模型，失败时自动升级重试。
